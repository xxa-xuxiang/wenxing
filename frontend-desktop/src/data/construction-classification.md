# 分类方式：按专业知识学习路径归纳

分类层级：

1. **第一层：专业知识大类**
2. **第二层：知识领域**
3. **第三层：核心知识模块**
4. **第四层：理论、方法、技术或岗位应用**

同一知识可在设计、施工、成本、采购、安全、运维等岗位方向中交叉出现，用于构建完整学习路径。
