# 分类方式：按专业知识学习路径归纳

分类层级：

1. **第一层：专业知识大类**
2. **第二层：知识领域**
3. **第三层：核心知识模块**
4. **第四层：理论、方法、技术或岗位应用**

同一知识会同时出现在市场研究、品牌、广告、公关、内容生产、媒介投放、设计、影视、音乐、游戏和数字商业等方向中，用于建立完整学习路径。
