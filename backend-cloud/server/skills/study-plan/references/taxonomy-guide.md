## 两种文件格式

- 甲编：单个 ` ```yaml ` 代码块，六级目录树——`编 → 族 → 项 → 知识点 → 子知识点 → 细目 → 条目`。知识点附带 `适用专业 / 证据载体 / 标签`。
- 乙编 / 丙编：散文式 Markdown，`# 标题` + `> 编／族` + `## 小节`（小节即知识点，段末附 `适用专业 / 证据载体 / 标签`）。

## 四个标签

- 迁移性（高/中/低）：跨岗位/跨领域的可迁移程度。
- AI风险（高/中/低）：被 AI 替代的风险。
- 半衰期（长/中/短）：知识/技能的有效期。
- 证：是否为执照门槛（"证"标记）。

## 读取规则

1. 先按 00-总览 的简写规则理解标签。
2. 用目标关键词匹配到 族，再落位到 项、知识点、子知识点。
3. 引用技能名时须与文件中原文完全一致，并标注 `族/项` 路径。
