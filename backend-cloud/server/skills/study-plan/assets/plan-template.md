## 五、可视化展示（Phase 4）

### 全局甘特图
- 横轴：总周期时间节点；纵轴：各模块；条形：起止时间 + 当前进度。
- 里程碑：周测/月考/阶段验收（达标绿 / 未达标红 / 待完成灰）。
- 偏差预警：落后 ≥10% 黄、≥20% 红，附补学方案。

### 辅助视图
- 日历视图：每日任务、完成打卡、复习提醒。
- 数据看板：总时长、任务完成率、知识点掌握率、连续打卡天数；近 7 天趋势；薄弱项突破进度。

## 六、弹性与跟进机制（Phase 4 & 5）

| 项 | 规则 |
|---|---|
| 每周弹性时间 | 2–3 小时（占 5%–10%） |
| 临时任务排序 | 紧急重要 > 重要不紧急 > 紧急不重要 > 不紧急不重要 |
| 进度滞后补学 | 1–3天：碎片补；4–7天：每日+30-60分；>7天：调周期（≤+20%） |
| 每日打卡 | 时长/完成任务/未完成及原因/收获，当日 10 分钟内 |
| 周复盘 | 完成率 + 掌握率 + 时间利用率 + 偏差原因，≥2 条改进 |
| 月总结 | 完成率分级（≥80/60-79/<60），未达标三维归因 |
| 薄弱专项 | 四步法，≥20 题、≥2 小时、专项测试 ≥85% |
| 动态调整触发 | 连续2周完成率<70% / 连续2次测试<60% / 环境变化≥30% |
