# 分类方式：按专业知识学习路径归纳

分类层级：

1. **第一层：专业知识大类**
2. **第二层：知识领域**
3. **第三层：核心知识模块**
4. **第四层：理论、方法、技术或岗位应用**

同一知识按人体与疾病机制、诊断治疗、药物与器械、医疗服务、公共卫生、健康管理和行业治理展开，用于构建完整学习路径。
