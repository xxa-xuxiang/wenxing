# 分类方式：按专业知识学习路径归纳

分类层级：

1. **第一层：专业知识大类**
2. **第二层：知识领域**
3. **第三层：核心知识模块**
4. **第四层：理论、方法、技术或岗位应用**

同一知识按内容创作、制作生产、表演与竞技、场馆运营、传播发行、用户消费、商业变现、数字化、法规、安全与组织管理展开，用于构建完整学习路径。
