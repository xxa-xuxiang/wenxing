# 分类方式：按专业知识学习路径归纳

分类层级：

1. **第一层：专业知识大类**
2. **第二层：知识领域**
3. **第三层：核心知识模块**
4. **第四层：需要掌握的理论、方法、技术或岗位应用**

同一知识会在机械、电气、材料、自动化、数字化、质量和供应链等方向交叉出现，以匹配真实学习与岗位迁移路径。
