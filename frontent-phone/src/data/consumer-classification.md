# 分类方式：按专业知识学习路径归纳

分类层级：

1. **第一层：专业知识大类**
2. **第二层：知识领域**
3. **第三层：核心知识模块**
4. **第四层：理论、方法、技术或岗位应用**

同一知识按行业经营、产品、服务、渠道、供应链、体验、数字化、财务、合规与组织管理展开，用于构建完整学习路径。
